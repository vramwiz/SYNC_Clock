# 時計演出（SYNC_Clock）

AviUtl2 のメディアオブジェクトとして追加できる時計プラグインです。Delphi / Direct2D で、時計の外装・針・数字・ガラス面を生成します。画像、フォント、音素材の追加は不要です。

## 使い方

1. AviUtl2 のメディアオブジェクト追加メニューで「時計演出」を選びます。Win64 ビルドの配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_Clock\SYNC_Clock.auf2` です。
2. 設定の先頭でプリセットを選び、**設定を反映**を押します。22スタイルから選べます。反映後はスタイル、色、描画モード、ガラス面などを個別に変更できます。
3. オブジェクトの先頭の日時と時間進行倍率を設定します。倍率は `0` で停止、`1` で等速、負の値で逆行します。
4. 位置・拡大率・回転・透明度は AviUtl2 の標準描画で調整します。

| 描画モード | 描画内容 |
| --- | --- |
| 時計全体 | 外装、文字盤、針・表示部など |
| 文字盤 | 文字盤、目盛、針・表示部など |
| 時刻表示のみ | 針・数字などの可動部 |

デジタル系で「カウントダウン」を選ぶと、時・分・秒は初期残り時間になります。砂時計は常にカウントダウンです。ストップウォッチは、時・分・秒を初期経過時間とします。アナログ版は秒針と30分積算計、デジタル版は1/100秒単位で経過時間を表示します。

ガラス面の「自動」は、ガラス付きスタイルの「時計全体」で有効になります。各モードで ON または OFF を明示できます。ガラスX/Yは文字盤・表示部の中心を基準とし、縦横比 `-100` と `100` でガラス面が消えます。

効果音は初期状態で OFF、音量は50です。目覚まし時計のアラームは「時計固有の動作」で有効にして時・分を設定します。

制作仕様は [docs/SPECIFICATION.md](docs/SPECIFICATION.md)、ビルド方法は [note.md](note.md) を参照してください。
